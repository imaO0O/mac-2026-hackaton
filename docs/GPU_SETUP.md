# Работа на видеокарте: что делать участнику с NVIDIA

Проект собран так, что **всё считается на CPU** и демо обязано работать на CPU
без интернета. Видеокарта — не требование, а способ попробовать модели, которые
на процессоре учить долго. Этот документ для тех, у кого NVIDIA есть.

## 1. Проверка, что карта видна

```bash
nvidia-smi
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

Если `torch` ещё не стоит, ставьте отдельно от `requirements.txt` — сборка
зависит от вашей версии CUDA:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu124   # CUDA 12.4
pip install torch --index-url https://download.pytorch.org/whl/cpu     # без CUDA
```

> **Ловушка Windows, на которой мы потеряли время.** Интерпретатор из Microsoft
> Store называется `python3.12`, а не `python`. Команда `Get-Process python`
> возвращает пустоту даже когда обучение идёт полным ходом, и легко решить, что
> процесс умер. Проверяйте так:
> ```powershell
> Get-Process | Where-Object { $_.ProcessName -like "*py*" }
> ```

## 2. Что в этом проекте имеет смысл считать на GPU

Порядок — по ожидаемой пользе. Первое реально может улучшить решение, третье
делает демонстрацию приятнее, второе скорее всего не окупится.

| Задача | Файл, куда подключать | Ожидание |
|---|---|---|
| TCN или GRU для прогноза серы | `models/quality_model.py`, интерфейс ниже | стоит попробовать: у бустинга 983 строки и 381 признак, последовательность может дать больше |
| LSTM-автоэнкодер вместо расстояния Махаланобиса | `models/anomaly.py` | сомнительно: переменных шесть, а объяснимость упадёт |
| Локальная LLM для формулировок | `agents/orchestrator.py`, метод `_explain` | косметика: числа всё равно берутся из структур агентов |

**Чего на GPU делать не нужно.** CatBoost и LightGBM на этих данных считаются на
процессоре за минуты — `task_type="GPU"` тут не даст ничего, кроме мороки со
сборкой.

## 3. Контракт: как подключить свою модель без правок системы

Агент качества обращается к модели ровно через два метода:

```python
class MyGpuModel:
    horizon_hours: float = 0.0      # горизонт прогноза
    alarm_threshold: float = 0.25   # порог тревоги, подобранный на валидации

    def predict_with_sigma(self, state) -> tuple[float, float]:
        """Прогноз серы, мг/кг, и σ. Обязательный метод."""

    def risk_for_state(self, state) -> float | None:
        """P(сера > 10 мг/кг). Необязательный: если его нет, риск считается из σ."""
```

Подключение:

```python
from nefte.agents.quality import QualityAgent
agent = QualityAgent(model=MyGpuModel())
```

Если хотите, чтобы вашей моделью пользовался ещё и оптимизатор через
статистический суррогат, добавьте `features`, `_row_for(state)` и
`predict_frame(rows)` — как в `SulfurModel`. Но проще этого не делать:
кинетический суррогат (`models/kinetics.py`) берёт у модели только уровень серы
через `predict_with_sigma`, а отклик на уставки считает по физике, и этого
достаточно.

## 4. Обязательные условия сравнения

Иначе результат нельзя будет защитить:

* то же разбиение по времени из `configs/config.yaml` — train до 2025-06-30,
  валидация до конца 2025, тест 2026, эмбарго 48 часов;
* те же базовые для сравнения: показание ПАК и предыдущий лабораторный анализ
  (`models/dataset.py::persistence_baselines`);
* фиксированный сид и записанный отчёт в `reports/`;
* метрики те же: MAE, покрытие 80 % интервала, precision и recall тревоги,
  ROC-AUC. Проще всего повторить формат `scripts/train_quality.py`.

Ориентир, который надо побить (тест 2026 года, nowcast): **MAE 1.30**, покрытие
интервала 0.85, ROC-AUC 0.83. Поточный анализатор для сравнения даёт MAE 1.48.

## 5. Бесплатный GPU, если своей карты нет

**Kaggle Notebooks** — 30 часов в неделю, P100 или 2×T4, сессия до 12 часов.
Google Colab — T4 с плавающими лимитами.

> **Осторожно с данными.** Выгрузка на Kaggle означает передачу данных
> организаторов на внешний сервис. Загружайте только **приватным** датасетом и
> сначала проверьте правила хакатона: если данные помечены как конфиденциальные,
> обучать в облаке нельзя вообще. Обученную модель возвращайте файлом
> (`*.pt`, `*.cbm`) и подключайте локально.

## 6. Правило, которое не обсуждается

**Демонстрация идёт на CPU, без интернета и без внешних сервисов.** Любая
GPU-модель либо экспортируется в файл и работает локально, либо в демо не
попадает. Система должна оставаться работоспособной, даже если ноутбук с
видеокартой в день защиты не включится.
