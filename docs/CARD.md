# Карточка оператора: каждая строка и на чём она стоит

Карточка — единственное, что оператор видит от системы. Поэтому каждая её строка
должна отвечать на три вопроса: откуда взято число, чем оно подтверждено и где
проходит граница между измеренным и допущенным. Ниже — карточка целиком и разбор
по строкам.

Воспроизвести:

```bash
python scripts/run_cycle.py --ts "2026-01-12 14:00"
```

## Откуда берётся каждая строка

| Строка | Число из | Чем подтверждено | Допущение |
|---|---|---|---|
| Заголовок: риск и прогноз | модель серы (CatBoost, квантили) + порог тревоги с валидации | ROC-AUC 0.82 на тесте, покрытие интервала 82 % | нет |
| Действие | оптимизатор: отсев по жёстким ограничениям → Парето → свёртка | одноагентная система двигает уставки в 12 раз больше | веса свёртки |
| Эффект | прогноз варианта против бездействия | приращение считает кинетика (порядок 1.5) | сила отклика |
| Проверено | явный список ограничений, включая НЕпроверенные | тесты «жёсткое ограничение нельзя оплатить выпуском» | границы уставок |
| Уверенность | множители: источник, возраст, ширина интервала, пригодность данных | ниже 0.7 ошибка в 3.1–3.5 раза больше (`reports/confidence_meaning.json`) | сами множители |
| Почему | трасса решения: кто из агентов что ограничил | тест на связность карточки и трассы | нет |
| Достоверность | расхождение двух поточных анализаторов | при расхождении > 2 мг/кг ошибка втрое выше (`reports/analyzer_disagreement.json`) | порог 2 мг/кг |
| Разбор причины | SHAP по группам каналов, только при необычной причине | сумма вкладов = прогноз, невязка 0.0000 (`reports/risk_attribution.json`) | группировка каналов |
| Возврат в норму | выход уставки за рабочий диапазон, шаг цикла и старение катализатора | тег выпадает из рассмотрения в 9.3 % моментов (`reports/out_of_bounds.json`); выходы T5 вверх целиком объясняются старением катализатора: 0.85 °C/мес по его возрасту из журнала замен (`reports/catalyst_life.json`) | сам диапазон |

| Смешение | рецептура блока смешения | доли дают 100 %, ЦЧ по марке | состав компонентов |

## Чего в карточке НЕТ и почему

Каждый пропуск — измеренный отказ, а не забытая функция.

**Разбора причины в каждом решении.** Ведущая группа каналов — «показания по сере»
в 85 % решений, а без неё «сырьё с АВТ» в 81 %. Постоянная строка стала бы фоном,
поэтому разбор появляется только тогда, когда причина необычна: 19 % решений на
тесте (`docs/QUALITY_AGENT.md`, «Почему прогноз такой»).

**Отказа при расхождении приборов.** Расхождение выше 2 мг/кг втрое увеличивает
ошибку оперативного значения, и соблазн отказываться в такие моменты велик. Правило
приёмки на прошлой сборке формально выполнялось лишь на одном пороге сетки из
четырёх — признак шума, а не эффекта, — а на финальной не выполняется ни на одном. Поэтому расхождение осталось пометкой достоверности и решений
не меняет (`reports/disagreement_decisions.json`).

**Числа шагов до нормы.** Одного шага обычно мало: 75 % эпизодов вмешательства
содержат больше одного действия. Но назвать число нельзя — межквартильный размах
вдвое больше медианы. Вместо обещания карточка называет ритм проверки: эффект
проявляется за ~4.6 ч (`reports/action_plan.json`).

**Цены в рублях.** Заказчик назвал только отношение: некондиция в 50–100 раз дороже
запаса по качеству, присадка ЦЧ — в 100 раз дороже топлива. Прямая подстановка этой
цены в ранжирование проверена и отклонена: система начинает резать сырьё, выпуск
падает вдвое сильнее (`reports/economic_ranking.json`). Поэтому в карточке — тонны
под риском, а не рубли.

**Рекомендаций при пуске и останове.** Если за время отклика режим ушёл больше чем
на пять шагов цикла, карточка не советует возврат, а говорит, что режим ведёт
технолог. Эксперт 11.09 (32:49) подтвердил: если система в эти моменты молчит, «это
не страшно».

## Что происходит, когда система отказывается

Отказ — это тоже решение, и он проверен (`reports/refusal_quality.json`, тест):

| Группа | Доля моментов | Превышений за 24 ч | Ошибка оперативного значения |
|---|---|---|---|
| с решением | 86.4 % | 17.5 % | 1.79 мг/кг |
| отказ: нет допустимых вариантов | 0.4 % | 20.0 % | 13.19 мг/кг |
| отказ: установка остановлена | 9.2 % | — | 15.70 мг/кг |
| отказ: данные недостоверны | 4.0 % | 24.2 % | 15.56 мг/кг |

Там, где система молчит из-за данных, поточный анализатор расходится с лабораторией
в 8.7 раза сильнее, чем в моментах с решением. Это и есть смысл отказа: не «система
не работает», а «данным в этот момент верить нельзя, и вот почему».

**Второе условие правила здоровья отказов сейчас не выполнено** — и мы это не прячем.
Правило (записано до счёта, `scripts/check_refusal_quality.py`) допускает в отказах по
данным долю превышений не больше, чем в моментах с решением, плюс 5 п.п. Сейчас
24.2 % против 17.5 %, разница 6.7 п.п. Сами отказы по данным почти не изменились (209
моментов, было 212; превышений 24.2 %, было 23.5 %) — сдвинулась база сравнения:
вето тяжести (22.09) перевело около 740 моментов конца цикла катализатора из отказа
«нет допустимых вариантов» в решения, а превышений в них мало (7.2 %). До вета
условие выполнялось: 23.5 % против 19.5 %. Отказов «нет допустимых вариантов»
теперь 0.4 % моментов вместо 14.6 %. При отказе карточка сохраняет строки достоверности, возврата в норму и
«что дальше» — именно там оператор спрашивает, когда станет понятнее.
